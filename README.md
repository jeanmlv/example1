# example1

Estou enfrentando um problema crítico de armazenamento na minha máquina virtual da Johnson & Johnson.

A máquina possui um disco C: com capacidade total de aproximadamente **127 GB**, dos quais cerca de **126 GB já estão ocupados**, restando apenas **1,14 GB disponível**.

Eu trabalho com análise e processamento de dados clínicos, principalmente arquivos CSV de grande volume, e atualmente não estou conseguindo salvar, baixar, copiar ou manipular alguns desses arquivos devido à falta de espaço.

Já tentei realizar uma limpeza pelo próprio Windows, mas não consegui liberar espaço suficiente.

Ao verificar as configurações de armazenamento, identifiquei:

- **Sistema e arquivos reservados:** 55 GB, incluindo aproximadamente 12,7 GB de hibernação e 11,4 GB de memória virtual.
- **Aplicativos instalados:** 37 GB.
- **Arquivos temporários:** 23,1 GB.
- **Área de trabalho:** 8 GB.

O que achei estranho é que o Windows indica aproximadamente 23 GB de arquivos temporários, mas a ferramenta de limpeza de disco disponibiliza apenas uma pequena parte desse espaço para exclusão.

Além disso, alguns arquivos estão apresentando problemas de sincronização com o OneDrive.

Gostaria de verificar se vocês conseguem identificar o que está consumindo tanto espaço, realizar uma limpeza segura dos arquivos desnecessários e, principalmente, **avaliar a possibilidade de aumentar a capacidade do disco da minha máquina virtual**.

Como trabalho frequentemente com datasets clínicos grandes, acredito que aumentar o armazenamento seria a solução mais adequada para evitar que esse problema continue acontecendo.
