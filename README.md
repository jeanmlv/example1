Low Disk Space on J&J Virtual Machine – Unable to Access and Process Clinical Data Files

I am experiencing a critical disk space issue on my J&J virtual machine, which is preventing me from accessing, downloading, and processing clinical datasets (ARD CSV files) required for my ongoing projects.

The virtual machine has a total disk capacity of 127 GB (C: drive), with approximately 126 GB currently used and only 1.14 GB available.

According to Windows Storage settings, the main storage usage categories are:

- System & Reserved: 55.0 GB (including 12.7 GB for the hibernation file and 11.4 GB for virtual memory)
- Installed Applications: 37.0 GB
- Temporary Files: 23.1 GB
- Desktop Files: 8.04 GB

Although Windows reports 23.1 GB of temporary files, the Disk Cleanup interface only identifies a small portion as available for removal.

As a result, I am receiving "Not enough space on disk" errors when attempting to access or copy clinical CSV files, and some files are showing OneDrive synchronization errors.

Could the IT team please:

1. Investigate the disk space usage and identify any unnecessary system or temporary files that can be safely removed.
2. Evaluate whether the hibernation file (12.7 GB) is required for this virtual machine and whether it can be safely disabled.
3. Check for any storage or OneDrive synchronization issues.
4. Consider increasing the virtual machine's disk capacity, as I regularly work with large clinical datasets that require additional storage for processing and analysis.

This issue is currently affecting my ability to work with clinical data and complete ongoing data analysis activities.

Thank you for your support.
