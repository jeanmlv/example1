Hi Tiffany! Thank you so much! I'm really glad you liked the dashboard!

Yes, I developed the dashboard using Python and Streamlit, and I designed its structure around the V-Squad's ARGES workflow.

The idea was to create a centralized platform where the team could easily explore and track information across our clinical studies, from study inventories and data availability to data processing, ARD generation, variable gap analysis, and other ARGES-related activities.

The dashboard is built around our ARGES_COMMONS Excel inventory, which serves as the central source of information. We continuously update this inventory as we receive new data and feedback from the team, and then synchronize those updates with the dashboard published in Domino.

I also organized the dashboard into different sections to make it easier to navigate and monitor each stage of the workflow.
